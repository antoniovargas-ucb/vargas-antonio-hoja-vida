Proyectos destacados

TeoZen - Plataforma Académica

Descripción: Plataforma académica integral orientada a la gestión educativa, seguimiento pedagógico, evaluación continua y optimización de los procesos de aprendizaje para estudiantes y docentes.

Tecnologías utilizadas: Python, JavaScript, HTML5, CSS3, bases de datos relacionales.

Rol desempeñado: Líder de Proyecto y Desarrollador Full Stack.

Resultado obtenido: Incremento comprobado del 90% en la tasa de retención y rendimiento de los estudiantes en programas formativos.

Calxircuit - Software de Cálculo y Simulación de Circuitos

Descripción: Software especializado en el análisis computacional, cálculo matemático y simulación algorítmica de circuitos eléctricos y electrónicos.

Tecnologías utilizadas: Python, librerías científicas de computación numérica, algoritmos de resolución circuital.

Rol desempeñado: Desarrollador Principal e Investigador.

Resultado obtenido: Proyecto seleccionado y presentado con distinción en el marco del Workshop 2024.

StyleMatch - Plataforma para compra de ropa

Descripción: Plataforma desarrollada fundamentalmente para la asignatura de Base de Datos I, orientada a la gestión y comercialización de prendas de vestir mediante consultas y estructuras relacionales en SQL, integradas con Java y HTML para proporcionar una interfaz agradable y funcional, demostrando con solidez el dominio en el modelado y administración de bases de datos.

Tecnologías utilizadas: SQL (tablas relacionales y consultas avanzadas), Java, HTML5, CSS3.

Rol desempeñado: Desarrollador y Diseñador de Base de Datos.

Resultado obtenido: Implementación exitosa del esquema de datos relacional y presentación destacada en la cátedra de Base de Datos I.

Sistema de Control Informatizado de Inventarios

Descripción: Plataforma desarrollada para la gestión, auditoría y control de stock de insumos tecnológicos y equipamiento.

Tecnologías utilizadas: HTML5, CSS3, JavaScript, Python.

Rol desempeñado: Desarrollador Principal y Diseñador de Arquitectura de Datos.

Resultado obtenido: Reducción del 30% en tiempos de consulta de inventario y cero pérdidas de registros en pruebas piloto.
